# CausalCool

AI-Powered Neighbourhood Urban Heat What-If Analysis

CausalCool is a proposed decision-support prototype that explores
how urban interventions may affect local heat conditions.

## Prototype

The prototype allows users to:

- Select a neighbourhood
- Select an urban intervention
- Choose the intervention level
- Run a what-if analysis
- View a model-based estimated effect
- Understand key heat drivers and assumptions

## Important Note

The current prototype uses illustrative values for demonstration.
The estimates are not guaranteed real-world outcomes and require
real-world data and field validation.
